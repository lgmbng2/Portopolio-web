# Design Guidelines

Website portfolio ini menggunakan desain modern, clean, dan profesional dengan sedikit sentuhan tech/digital. Desain tidak boleh terlihat terlalu ramai, terlalu neon, atau seperti template AI generik.

## Visual Direction

Gunakan tampilan dark professional, bukan cyberpunk penuh.

Nuansa utama:
- Profesional
- Rapi
- Modern
- Developer-focused
- Minimal tetapi tetap interaktif
- Tidak terlalu ramai
- Tidak terlalu banyak efek glow

## Color System

Gunakan warna gelap sebagai dasar, tetapi hindari hitam pekat murni di semua bagian.

Warna utama:
- Background utama: #080B12 atau #0B1120
- Surface/card: #111827 atau #101624
- Surface kedua: #161F2E
- Teks utama: #F8FAFC
- Teks sekunder: #94A3B8
- Border: rgba(255, 255, 255, 0.08)

Warna aksen utama:
- Cyan atau blue digunakan sebagai aksen utama.
- Purple hanya digunakan sedikit untuk highlight.
- Green hanya digunakan untuk status/indikator kecil, bukan warna dominan.

Hindari:
- Terlalu banyak warna neon dalam satu section.
- Gradient berlebihan di setiap card.
- Background penuh efek aurora/glow yang terlalu mencolok.
- Warna pelangi pada semua elemen.

## Layout Rules

Gunakan layout yang lega dan mudah dibaca.

Aturan layout:
- Maksimal lebar konten sekitar 1120px sampai 1200px.
- Setiap section memiliki spacing yang konsisten.
- Jangan membuat semua section berbentuk card.
- Beri variasi layout antar section agar tidak terlihat seperti template.
- Hero section harus sederhana, kuat, dan langsung menjelaskan siapa pemilik portfolio.
- Skill Keyboard boleh menjadi bagian paling interaktif, tetapi section lain tetap clean dan profesional.

## Component Style

Gunakan rounded corner sedang, bukan terlalu besar di semua elemen.

Aturan komponen:
- Gunakan rounded-xl atau rounded-2xl sebagai default.
- Gunakan rounded-3xl hanya untuk section/card besar tertentu.
- Shadow digunakan secara halus.
- Border tipis lebih diutamakan daripada shadow besar.
- Glassmorphism hanya digunakan pada elemen tertentu, bukan seluruh website.
- Card harus terlihat ringan dan rapi, bukan seperti efek kaca berlebihan.

## Skill Keyboard Section

Skill Keyboard adalah elemen khas utama website.

Aturan desain:
- Tombol skill dibuat menyerupai keycap keyboard.
- Setiap tombol boleh memiliki warna aksen sesuai logo teknologi, tetapi tetap dikontrol agar tidak terlalu ramai.
- Logo skill harus jelas dan proporsional.
- Saat hover, tombol boleh naik sedikit atau terlihat aktif.
- Saat klik/tap, tombol boleh terlihat seperti ditekan.
- Deskripsi skill muncul secara dinamis di panel atau area khusus.
- Jangan membuat tombol terlalu besar sampai mengganggu layout.
- Jangan gunakan efek 3D berlebihan pada versi awal.
- Jangan gunakan Three.js kecuali diminta.

## Typography

Gunakan font yang modern dan mudah dibaca.

Aturan:
- Heading harus jelas, tegas, dan tidak terlalu dekoratif.
- Body text harus nyaman dibaca.
- Hindari terlalu banyak ukuran font berbeda.
- Gunakan maksimal 2 jenis font.
- Jangan gunakan teks gradient terlalu sering.
- Teks gradient hanya boleh digunakan untuk nama atau highlight penting.

## Animation Rules

Animasi harus mendukung pengalaman pengguna, bukan hanya hiasan.

Gunakan:
- Fade in ringan
- Slide up ringan
- Hover lift kecil
- Press effect pada tombol keyboard
- Transition 200ms sampai 500ms

Hindari:
- Animasi terlalu cepat
- Animasi terlalu lambat
- Terlalu banyak elemen bergerak bersamaan
- Bounce berlebihan
- Glow berkedip
- Parallax berlebihan
- Animasi yang mengganggu pembacaan konten

## Responsive Rules

Website harus nyaman di desktop, tablet, dan mobile.

Aturan:
- Skill Keyboard di desktop boleh berbentuk grid seperti keyboard.
- Di mobile, Skill Keyboard harus tetap rapi, bisa menjadi grid 2 kolom atau horizontal scroll.
- Jangan memaksakan tampilan desktop di layar kecil.
- Ukuran teks dan tombol harus tetap nyaman disentuh di mobile.
- Navbar mobile harus sederhana dan mudah digunakan.

## Anti-AI Template Rules

Hindari pola desain yang terlalu sering terlihat pada website hasil AI, seperti:
- Semua section memakai glass card.
- Terlalu banyak gradient ungu-biru.
- Glow besar di setiap sudut.
- Teks seperti "Crafting digital experiences" yang terlalu generik.
- Animasi muncul berlebihan di setiap elemen.
- Icon terlalu banyak tanpa fungsi jelas.
- Layout card yang terlalu simetris dan kaku.
- Semua section memiliki pola yang sama.

Desain harus terasa seperti portfolio developer sungguhan: jelas, personal, rapi, dan fokus pada karya.
