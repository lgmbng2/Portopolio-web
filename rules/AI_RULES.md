# AI Rules

Ikuti aturan berikut saat membantu mengembangkan project ini.

## General Rules
- Jangan mengubah struktur project tanpa alasan yang jelas.
- Jangan menghapus fitur yang sudah ada kecuali diminta.
- Jangan mengganti tech stack utama.
- Jangan membuat kode terlalu kompleks jika solusi sederhana sudah cukup.
- Jangan menambahkan library baru tanpa menjelaskan alasan penggunaannya.
- Selalu pertahankan desain dark futuristic yang profesional.
- Selalu pastikan tampilan responsive.

## Coding Style
- Gunakan React functional components.
- Gunakan Tailwind CSS untuk styling.
- Gunakan Framer Motion hanya untuk animasi yang memang perlu.
- Gunakan React Icons untuk icon skill dan social media.
- Pisahkan data ke folder src/data.
- Pisahkan komponen ke folder src/components.

## Design Behavior
- Jaga konsistensi warna, spacing, shadow, dan rounded corner.
- Jangan membuat desain terlalu ramai.
- Gunakan animasi halus dan tidak berlebihan.
- Pastikan setiap elemen mudah dibaca.
- Pastikan kontras teks cukup jelas.

## Output Rules
- Saat memberikan kode, jelaskan file mana yang harus dibuat atau diubah.
- Jangan memberikan potongan kode tanpa konteks lokasi file.
- Jika mengubah banyak file, urutkan dari file paling penting.
- Jangan mencampur instruksi desain dan kode dalam satu file jika tidak perlu.

## Portfolio Goal
Website ini harus terlihat seperti portfolio developer modern, bukan template biasa. Bagian Skill Keyboard harus menjadi ciri khas utama website.
