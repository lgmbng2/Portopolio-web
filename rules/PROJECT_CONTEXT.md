# Project Context

Project ini adalah website portfolio pribadi milik Muhammad Aditya.

Website ini dibuat untuk menampilkan profil, skill, pengalaman, pendidikan, project, dan kontak secara profesional.

Target utama website ini adalah sebagai portfolio untuk kebutuhan karier di bidang IT, khususnya web development, mobile development, backend development, dan sistem informasi.

Tech stack utama:
- React Vite
- Tailwind CSS
- Framer Motion
- React Icons

Gaya website:
- Modern
- Dark futuristic
- Profesional
- Interaktif
- Smooth animation
- Responsive di desktop dan mobile


Salah satu bagian utama website adalah Skill Keyboard Section, yaitu tampilan skill berbentuk tombol keyboard interaktif seperti mechanical keyboard. Setiap tombol berisi logo skill dan ketika hover atau klik akan menampilkan deskripsi skill, bagian ini akan muncul ketika memasuki halaman skill dengan animasi yang mulus
